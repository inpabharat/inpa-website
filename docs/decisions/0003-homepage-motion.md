# Homepage motion

The hero uses an image-led, manually controlled slideshow with previous/next buttons, direct slide selection, keyboard arrows and horizontal touch swipes. No automatic rotation interrupts reading. With no published slides the existing scientific focus list remains visible.

Navigation panels use a short fade and vertical transition. Desktop homepage sections reveal once with a 24px upward movement as they enter the viewport. Content is visible in server-rendered HTML; the effect is added only after mounting, does not intercept scrolling, and is disabled on smaller screens and for reduced-motion preferences. Keyboard focus also reveals content immediately.

No motion library, new media, database migration or paid service is required.
