# ADR 0001: Adopt Nuxt 4.5.1

- Date: 2026-08-01
- Status: Accepted

## Context

The initial specification required Nuxt 3. During Phase 0 implementation, the user explicitly requested moving to Nuxt 4.5.1 if the migration was not disruptive. The scaffold was still new and already used the top-level `app/` structure, so the change did not require a product or persistence redesign.

Nuxt 4.5.1 is the current patched 4.x security release. The corresponding patched 3.x release would have been 3.21.10.

## Decision

Use Nuxt 4.5.1 with Vue 3 and strict TypeScript. Retain the approved Cloudflare Workers, D1, R2, Drizzle and Cloudflare Access architecture.

## Consequences

- The project uses Nuxt 4's native `app/` directory convention.
- The explicit user decision recorded here supersedes the earlier Nuxt 3 constraint in `CODEX_AGENT.md`.
- Future upgrades remain deliberate and must pass lint, type checking, tests and the Cloudflare production build.
